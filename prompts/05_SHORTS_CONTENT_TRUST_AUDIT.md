# ביקורת אמינות ותיקון ספריית הקצרים — גרסת מסמך 1.0.0

גרסת מוצר יעד: **3.2.0**.

## מטרה

לתקן את כשל האמון שנחשף כאשר צמיג בשם Motoz Tractionator GPS הופיע בקטגוריית ניווט, ולבנות מחדש את ספריית הקצרים לפי תוכן מוכח ולא לפי מילות מפתח.

## דרישות מחייבות

- לבדוק מחדש את כל 806 הרשומות שפורסמו ב־3.1.0.
- כותרת לבדה או תמונת תצוגה לבדה אינן מספיקות.
- לדרוש הסכמה בין כותרת, תיאור מקור ובדיקה חזותית פרטנית בנגן YouTube.
- להסיר כל פריט מסופק, עמום, פרסומי, בידורי, לא זמין או כזה שלא ניתן לאמת בביטחון גבוה.
- לתקן קטגוריות רק כאשר כל הראיות מסכימות; אין למלא מכסת קצרים או שלבי לימוד בכוח.
- לעדכן גרסת מוצר ומסמכים, לבנות Standalone ומראת `site/`, להריץ את כל שערי האיכות ולפרסם ל־GitHub Pages.
