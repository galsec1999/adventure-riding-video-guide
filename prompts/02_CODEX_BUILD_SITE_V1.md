# משימה 02 — Codex: בניית אתר V1 על נתוני אמת

## התפקיד שלך

אתה מוביל הפיתוח וה־QA. עבוד ישירות בתיקייה הפתוחה. קרא תחילה:

- `MASTER_SPEC.md`
- `AGENTS.md`
- `DECISIONS.md`
- `QUALITY_GATES.md`
- `HANDOFF_TO_CODEX.md`
- כל הקבצים תחת `data/`, `schema/` ו־`reports/`

אל תשנה עובדות, תקצירים, דירוגים או סיווגי תוכן אלא לצורך תיקון טכני ברור ומתועד. בעיית תוכן תירשם לדוח ולא "תתוקן" בהמצאה.

## תוצאה נדרשת בסבב הזה

בנה אתר סטטי מקצועי, מהיר ומוכן לבדיקה, המבוסס על 60 הסרטונים האמיתיים הקיימים. אין להשתמש בנתוני דמה ב־Production.

## ארכיטקטורה

העדף HTML, CSS ו־JavaScript מודרני במודולים, ללא Framework כבד וללא Backend. מותר להשתמש בכלי Node קטנים לבדיקות ולבנייה אם הם מוסיפים ערך ברור. האתר הסופי חייב להיות ניתן לפרסום ב־hosting סטטי.

אם טעינת JSON דורשת שרת מקומי, צור:

- `run-local.bat` עבור Windows.
- `run-local.sh` עבור Linux/macOS.
- כלי שרת מקומי פשוט שאינו דורש הגדרה מורכבת.

## תכונות חובה

### ממשק וניווט

- עברית מלאה ו־RTL.
- Mobile First.
- מצב כהה ובהיר.
- דף בית עם כניסות ברורות לשטח, כביש, משולב, מסלולי לימוד וכל הסרטונים.
- כותרת, ניווט ומסננים נוחים בטלפון.
- עיצוב מקצועי בעל אופי אדוונצ'ר, לא חנות ולא עמוד צעצוע.

### ספריית סרטונים

- כרטיסים עם thumbnail, כותרת עברית ומקורית, ערוץ, שפה, משך כאשר קיים, רמה, תחום, תקציר ותגיות.
- חלון/עמוד פרטים מלא.
- נגן YouTube ללא autoplay, רצוי דרך `youtube-nocookie.com`.
- אין ליצור iframe עד שהמשתמש לוחץ לצפייה.
- Lazy loading לתמונות.
- קישור ישיר ל־YouTube.
- סרטונים קשורים.

### חיפוש וסינון

- חיפוש בעברית ובאנגלית.
- שימוש ב־`data/synonyms.json`.
- נרמול סימני פיסוק, אותיות סופיות וכתיבים חלופיים ככל שסביר.
- מסננים משולבים: תחום, קטגוריה, שפה, רמה, סיכון, סוג אופנוע, משקל אופנוע, סוג קרקע, תנאי דרך, כתוביות, מקור מקצועי ותוכן שיווקי.
- מספר תוצאות בזמן אמת.
- איפוס מסננים.
- מיון לפי המלצה, רמה, משך, תאריך, ערוץ ודירוג.
- מצב "אין תוצאות" מועיל.

### מצב משתמש מקומי

- מועדפים ב־localStorage.
- סימון נצפה.
- התקדמות במסלולי לימוד.
- "המשך מהמקום שבו עצרת".
- שמירת theme.
- שיתוף קישור לסרטון ולמצב מסננים באמצעות URL.

### מסלולי לימוד

- תצוגה מלאה של המסלולים הקיימים.
- שלבים, סרטון ראשי, חלופות והתקדמות.
- אין להציג ID חסר.

### בטיחות, זכויות ונגישות

- הצג אזהרת בטיחות מהמפרט.
- עמוד/חלון מקורות וזכויות.
- קרדיט לערוצים וקישור למקור.
- נגישות מקלדת, focus ברור, labels, alt text וניגודיות טובה.

## כלי תחזוקה ובדיקות

צור לפחות:

- `tools/validate_data.py` או `.js` — אימות Schema, IDs, references, tags/categories וכפילויות.
- `tools/check_links.py` או `.js` — בדיקת URL וסטטוס ציבורי בשיטה חוקית וזמינה; תמוך ב־dry-run ובדוח. אין להבטיח אימות שלא ניתן לבצע.
- `tools/build_audit.py` או `.js` — יצירת דוחות CSV/JSON/HTML.
- בדיקות יחידה לחיפוש, נרמול, פילטרים ו־storage.
- בדיקת smoke לדף.

צור `README.md` בעברית עם:

- הפעלה מקומית.
- הרצת בדיקות.
- הוספת סרטון.
- שינוי קטגוריות.
- בדיקת קישורים.
- בניית דוח.
- פרסום ב־GitHub Pages או hosting סטטי אחר.
- שינוי שם, לוגו, קהילה ופרטי קשר.

## Git

1. אם אין Git repository, אתחל אותו.
2. צור branch בשם `phase-02-site-v1`.
3. הוסף `.gitignore` מתאים.
4. בצע commit רק לאחר שהבדיקות עוברות.
5. אם קיים remote מאומת וניתן בבטחה ליצור PR, צור PR. אחרת השאר commit מקומי ותעד את הפקודה הבאה הנדרשת — בלי לעצור את שאר העבודה.

## בדיקות קבלה

הרץ ותעד לפחות:

- אימות כל 60 הרשומות.
- אפס כפילויות.
- כל קישורי ID הפנימיים תקינים.
- חיפוש המילים: חול, בוץ, פניות בכביש, בלימת חירום, הרמת אופנוע, גשם, עלייה תלולה, רכיבה איטית.
- שילוב של לפחות שלושה מסננים במקביל.
- רינדור Desktop ו־Mobile.
- פתיחת נגן רק לאחר לחיצה.
- שמירת מועדף/נצפה לאחר רענון.
- בדיקת RTL ומקלדת.
- בדיקות אוטומטיות עוברות ללא שגיאות.

צלם screenshots מקומיים ל־`reports/screenshots/` אם סביבת העבודה מאפשרת. אין להמציא שהצילום בוצע אם לא בוצע.
