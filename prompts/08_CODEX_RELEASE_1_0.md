# משימה 08 — Codex: גרסה 1.0 מוכנה לפרסום

קרא את כל מפרטי הפרויקט, הדוחות ו־review packets. בצע סגירה מלאה לגרסה 1.0.

## דרישות סיום

- כל הסרטונים המאושרים נטענים ומוצגים.
- מינימום 200; יעד 250 לפי תוצאת Work.
- אפס נתוני דמה וכפילויות.
- Schema, references, filters, search ו־storage עוברים בדיקות.
- בדיקת קישורים עדכנית ומתועדת.
- Mobile, Desktop, RTL, נגישות וביצועים עוברים.
- עמודי בטיחות, מקורות וזכויות מלאים.
- README והוראות פרסום מלאים.
- צור תיקיית `dist/` או חבילת static release נקייה.
- צור `RELEASE_NOTES.md`.
- צור `FINAL_AUDIT.md` עם תנאי הסיום אחד־אחד ו־PASS/FAIL אמיתי.
- אין לכתוב PASS כאשר בדיקה לא הורצה.

עבוד ב־branch `release/1.0`, בצע commit ו־tag `v1.0.0` רק אם כל שערי החובה עוברים. אם קיים remote מאומת, צור PR/Release לפי האפשרויות; אחרת תעד פקודות קצרות לביצוע ידני.

בסיום:

- עדכן `PROJECT_STATUS.md` ל־8/8 ול־100% רק אם השחרור באמת עבר.
- צור `REVIEW_PACKET.md` סופי.
- עדכן `NEXT_ACTION.md` ל־"נדרשת ביקורת אילן וניקי לפני פרסום".
- עצור.
