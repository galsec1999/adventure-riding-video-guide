# Adventure Riding Video Guide v2.3.0 PWA

גרסת GitHub Pages ציבורית וניתנת להתקנה של חבילת v2.2.1 הדו־לשונית.

## עיקרי הגרסה

- 450 סרטוני הדרכה מאומתים בעברית ובאנגלית.
- 175 ערוצים ו־17 מסלולי לימוד.
- PWA עם Manifest, אייקונים, Service Worker ו־app shell לא מקוון.
- ממשק עברי RTL ואנגלי LTR, רספונסיבי למחשב ולמובייל.
- עדכון Service Worker בהסכמת המשתמש בלבד.
- GitHub Actions לאימות ולפריסה ב־GitHub Pages.

## מגבלה חשובה

האתר והספרייה יכולים להיטען ללא חיבור לאחר ביקור ראשון, אך סרטוני YouTube עצמם דורשים אינטרנט ואינם נשמרים במטמון.
