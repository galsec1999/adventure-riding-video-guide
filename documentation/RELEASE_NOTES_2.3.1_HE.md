# הערות שחרור — גרסת מוצר 2.3.1 — גרסת מסמך 2.3.1

## מה השתנה

- הקרדיט הציבורי מציג „אילן” בלבד, ללא שם משפחה וללא שורת זכויות יוצרים אישית.
- שורת הזכויות באתר נוסחה מחדש כשורת פרויקט קהילתי.
- לכל מסמך שמשתנה בפרויקט נדרש מעתה מספר `גרסת מסמך` גלוי בכותרת, והמספר יועלה בכל שינוי עתידי.
- קובץ ה־HTML העצמאי, תצורת האתר, ה־Manifest ומטמון ה־Service Worker מסומנים כגרסה 2.3.1.

## תאימות ותוכן

מאגר התוכן נשאר ללא שינוי: 450 סרטונים מאומתים. השחרור אינו מוריד או שומר סרטוני YouTube ואינו משנה את רישיונות הקוד והתוכן.
