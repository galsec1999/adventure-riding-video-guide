# מדריך הווידאו הקהילתי לרכיבת אדוונצ׳ר — גרסת מוצר 3.3.0 — גרסת מסמך 3.3.0

אתר סטטי, עברי ו־RTL שמרכז סרטוני YouTube מסווגים לרכיבת אדוונצ׳ר, שטח, כביש, תרגול, בטיחות וטיולים. הוא נועד להרחיב ידע, להציע מסלולי לימוד ורעיונות לתרגול, ולסייע בתכנון טיול — ללא הרשמה, ללא שרת אפליקציה, ללא פרסומות מטעם האתר וללא כוונת רווח.

## מה יש בגרסה

- **411 סרטונים מלאים ייחודיים ופעילים**: 69 בעברית ו־342 באנגלית.
- **152 קצרים בביטחון גבוה**: 795 מועמדים מוסגרים נבדקו מחדש מול מקור חי, ומתוכם 180 עברו גם בדיקה חזותית פרטנית בשתי נקודות זמן.
- **17 סרטונים ממוקדים חדשים**: 6 ניווט, 7 מיגון ו־4 דיבוריות; 56 רשומות חלשות או לא זמינות הוסרו מן הבסיס הקודם.
- 6 תחומים ראשיים, 47 קטגוריות מבוקרות, 71 מיקודים ו־8 סוגי הדרכה.
- **17 מסלולי לימוד** מדורגים, עם חלופות צפייה והתקדמות שנשמרת במכשיר.
- מרכז טיולים: טיול יום, מסע רב־יומי וטיול בחו״ל.
- 7 קבוצות צ׳קליסט: אופנוע, רוכב, קבוצה, כלי כביש, כלי שטח, ניווט ומסמכי חו״ל.
- 10 כרטיסי השוואת ניווט, לרבות OsmAnd, REVER, Gaia GPS, DMD2, Waze/Google Maps, כלי Off-Road ופתרונות טלפון/GPS/שיקוף.
- חיפוש דו־לשוני עם מילים נרדפות ותיקון התאמות עברית שגויות.
- חיפוש חכם רגיל וחיפוש סמנטי אופציונלי שפועלים **מקומית בדפדפן** ואינם שולחים את השאלה לשירות AI.
- מסננים תלויי־הקשר: בחירת כביש מציגה רק נושאי כביש; בחירת קטגוריה ראשית מעדכנת את הנושאים המשניים.
- מועדפים, סימון נצפה, התקדמות במסלולים וצ׳קליסט טיול נשמרים במכשיר.
- כפתור משוב שמכין פנייה ל־GitHub — אין טופס שרת ואין איסוף מידע באתר.
- מונה טעינות חיצוני של האתר החי, עם הסבר מפורש שאינו סופר אנשים ייחודיים ועם fallback במקרה חסימה.
- כפתור להורדת HTML עצמאי מלא מתוך האתר.

## שני אופני שימוש

### 1. קובץ HTML עצמאי

הקובץ:

```text
downloads/Adventure-Riding-Video-Guide-v3.3.0-Standalone.html
```

כולל בתוכו את HTML, CSS, JavaScript וכל קובצי ה־JSON. אפשר להעביר אותו לטלפון ולפתוח בדפדפן בלי להקים שרת. חיבור לאינטרנט נדרש רק להצגת תמונות YouTube ולפתיחת הסרטונים עצמם.

בדפדפנים מסוימים פתיחת קובץ שהגיע מ־WhatsApp או מאפליקציית מסרים תוצג בתוך חלון תצוגה מוגבל. במקרה כזה שומרים את הקובץ למכשיר ופותחים אותו ב־Chrome, Edge, Safari או Firefox.

### 2. אתר מודולרי לפרסום

מבנה האתר:

```text
index.html
assets/
data/
downloads/
```

מעלים את כל התוכן הזה יחד לשורש של שירות hosting סטטי. אין צורך ב־Backend או במפתח YouTube.

## הפעלה מקומית של האתר המודולרי

פתיחה ישירה של `index.html` ב־`file://` עלולה לחסום טעינת JSON. לכן משתמשים בשרת המקומי המצורף.

### Windows

```powershell
.\run-local.bat
```

### Linux / macOS

```bash
chmod +x run-local.sh
./run-local.sh
```

לאחר מכן פותחים:

```text
http://127.0.0.1:8000/
```

## ניווט וחיפוש

האתר מציע ארבע כניסות פשוטות:

1. מסלול לימוד לפי סדר.
2. חיפוש נושא מסוים בספרייה.
3. תכנון טיול.
4. שאלה בשפה חופשית.

### מסננים תלויי־הקשר

- `תחום ראשי` מצמצם את רשימת הקטגוריות הראשיות.
- `קטגוריה ראשית` מצמצמת את רשימת הנושאים המשניים.
- סוגי תוואי ותנאי דרך מופעלים רק כאשר הם רלוונטיים.
- בחירה שהתיישנה בעקבות שינוי תחום מתאפסת אוטומטית, כדי שלא יישאר מסנן נסתר שמחזיר אפס תוצאות.

### החיפוש החכם המקומי

העוזר המקומי מזהה בין היתר:

- כביש, שטח, טיול, בטיחות ותרגול.
- רמת ניסיון.
- אופנוע כבד או קל.
- מושגים כגון ABS, חול, בוץ, GPX, זיווד, קבוצה, רוח וגשם.

ברירת המחדל אינה מערכת AI מרוחקת: היא מדרגת את 411 הרשומות המקומיות בעזרת טקסט, תגיות, מילים נרדפות וכוונת המשתמש. בהסכמה מפורשת אפשר להפעיל embeddings רב־לשוניים באמצעות מודל מקובע שרץ ב־Web Worker במכשיר. הורדת המודל הראשונה מגיעה מ־Hugging Face; לאחר הטעינה השאילתה אינה נשלחת ל־API או לשרת AI. כשל במודל מחזיר אוטומטית לחיפוש הרגיל. כפתור נפרד מאפשר גם להעתיק Prompt לכלי מקומי אחר שהמשתמש בוחר.

## הבהרת בטיחות

האתר **אינו תחליף** לקורס, לאימון מתקדם, להדרכה מעשית או למשוב של מומחה. אי אפשר ללמוד רכיבה מתקדמת באמת דרך הטלפון.

אילן עבר קורסי כביש ושטח, לרבות Level 1 ו־Level 2, וכל אחד מהם תרם רבות. המדריך נועד להשלים את הקורסים: לתת דגשים, רעיונות לתרגול, נקודות לקשב ושפה משותפת. השילוב בין קורסים מקצועיים, אימון מדורג, טיולים והרחבת הידע יכול להפוך אותנו כקהילה לרוכבים טובים ובטוחים יותר.

יש לתרגל בהדרגה, במקום מתאים, עם ציוד מיגון ובהתאם לחוק, לתנאי הדרך, למצב האופנוע ולרמת הרוכב. הוראות היצרן ומדריך מוסמך גוברים על סרטון או תקציר.

### מצב בדיקת הקישורים

כל 411 הכתובות עוברות בדיקת עקביות מקומית מול מזהה YouTube ושער רשת מלא לפני השחרור. 17 התוספות הממוקדות נבדקו ב־5 באוגוסט 2026; 78 רשומות ותיקות בעלות ראיית מטא־דאטה חלשה נבדקו מחדש, ומתוכן נשמרו רק 25 בעלות תמיכה וביטחון גבוה. זמינות YouTube עלולה להשתנות בעתיד, ולכן כפתור המשוב מאפשר לדווח על קישור שבור.

## הוספת סרטון בעתיד

1. בודקים שהסרטון ציבורי ורלוונטי.
2. בסרטון מלא בודקים תיאור, Chapters, כתוביות/תמלול או חלקים רלוונטיים. בקצר דורשים גם התאמה בין הכותרת לתיאור מקור וגם בדיקה חזותית פרטנית.
3. אין להסתמך על כותרת או thumbnail בלבד.
4. כותבים תקציר עברי מקורי ומציינים מגבלות.
5. משתמשים רק בערכים המבוקרים ב־`data/categories.json`.
6. משאירים שדה ריק כאשר אין ראיה; אין להמציא משך, תאריך, כתוביות או נקודת זמן.
7. מריצים את כל הבדיקות ובונים מחדש את ה־HTML העצמאי.
