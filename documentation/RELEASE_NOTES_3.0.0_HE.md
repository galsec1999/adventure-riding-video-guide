# הערות שחרור מוצר 3.0.0 — גרסת מסמך 1.0.0

גרסה 3.0.0 הופכת את האתר ממאגר גדול למדריך החלטה ולמידה דו־לשוני, עם חיפוש מקומי, מסלולים ברורים, מרכז טיולים עשיר יותר ושכבת AI אופציונלית שפועלת במכשיר ללא API או Backend.

## מה חדש

- 411 סרטונים פעילים: 69 בעברית ו־342 באנגלית, מ־165 ערוצים.
- 17 מסלולי לימוד ובהם 136 שלבים ו־416 הפניות לסרטונים.
- מסלול ניווט ו־GPX בן 8 שלבים, 10 השוואות של כלי ניווט ו־6 מדריכי החלטה למערכות ניווט, מיגון ודיבוריות.
- 17 מקורות חדשים וממוקדים: 6 ניווט, 7 מיגון ו־4 דיבוריות, ללא רכיב שיווקי מתועד.
- ספרייה עם היררכיית תחום ← נושא ← מיקוד, מסנני הקשר, חיפוש משופר וכרטיסים עשירים יותר.
- תזכורת בולטת לתת Like ביוטיוב ליוצרים שסייעו, כדי לעודד המשך השקעה בתוכן.
- דיסקליימרים חזקים יותר: המדריך הוא אוצר קישורים קהילתי, אינו בעל התוכן, אינו מאשר איכות ואינו מחליף הדרכה מקצועית.
- AI סמנטי מקומי אופציונלי באמצעות `multilingual-e5-small`; ההפעלה הראשונה מורידה כ־140MB למטמון הדפדפן והשאלה אינה נשלחת לשרת AI.
- חיפוש דטרמיניסטי מלא נשאר זמין תמיד, גם בלי מודל, ללא רשת או כאשר WebAssembly חסום.
- מונה טעינות בדף הבית באתר החי, עם גילוי מפורש שמדובר בטעינות ולא במבקרים ייחודיים ושגם רענונים ובוטים עשויים להיספר.
- עברית RTL ואנגלית LTR, מצבי Light/Dark, תצוגות Desktop/Mobile, PWA וקובץ HTML עצמאי.
- הקרדיט הציבורי הוא „אילן” בלבד; אין שם משפחה, כתובת אימייל החושפת אותו או שורת © אישית.

## שינוי בסיס התוכן

הבסיס הקודם כלל 450 רשומות. ב־3.0.0 נוספו 17 מקורות ממוקדים, הוסרו 3 קישורים לא זמינים, ולאחר ביקורת ראיות של 78 רשומות חלשות הוסרו 53 רשומות שלא עמדו בשער השמרני. החישוב הסופי הוא: **450 + 17 − 3 − 53 = 411**.

## מגבלות ידועות

- בדיקת איכות העריכה המחמירה נשארת FAIL עם חוב Legacy מתועד; אין להציג אותה כ־PASS. המספרים ותוכנית הטיפול נמצאים ב־`documentation/CONTENT_DEBT_3.0.0_HE.md`.
- מונה הטעינות מסתמך על שירות חיצוני קטן ורק בדומיין החי; חסימה או תקלה מציגות fallback ולא תמונה שבורה.
- הורדת המודל תלויה בתמיכת הדפדפן ב־Web Worker וב־WebAssembly. ה־Standalone משתמש בחיפוש הרגיל בלבד ומסביר זאת בממשק.
- האתר אוצר קישורים ומטא־דאטה; סרטוני YouTube, שמע ותמלילים אינם נשמרים בפרויקט.

## קובץ עצמאי

`downloads/Adventure-Riding-Video-Guide-v3.0.0-Standalone.html` מכיל את 411 הרשומות ואת החיפוש הרגיל בקובץ יחיד. שכבת ה־AI הסמנטית אינה נארזת בו כדי להימנע ממודל חיצוני גדול ומציפייה שגויה להפעלה Offline מלאה.
